A앱 딥링크 — 빵집 상세

기대: 빵집 상세가 웹뷰 위에 열리고, 뒤로가기로 이 위치(스크롤 유지)로 돌아온다. GA webview_deeplink_click(link_type=bakery).

르쿠에르 상세 열기 없는 빵집 ID (404 안내 확인)

B허용 호스트 안 이동

기대: 같은 웹뷰 안에서 이동. 앱바 ←로 돌아온다. Android 하드웨어 뒤로가기는 웹 뒤로.

샘플 이벤트 페이지로 이동(같은 호스트) 페이지 맨 위로(해시 이동)

C허용 호스트 밖 링크

기대: 외부 브라우저로 열리고 웹뷰는 그대로 남는다. 허용 밖 페이지가 웹뷰에 한 프레임도 그려지면 안 된다.

bbangmorning.com (https, 허용 밖) example.com (http) 같은 호스트 → meta refresh 로 허용 밖 이동 같은 호스트 → JS location 으로 허용 밖 이동
스크롤 영역 2

Dweb?url= 링크

기대: 허용 호스트면 같은 웹뷰에서 로드, 허용 밖이면 외부 브라우저.

web?url= → 허용 호스트(github.io) web?url= → event.bbangmorning.com web?url= → 허용 밖(bbangmorning.com)

E특수 스킴

기대: tel·mailto는 외부 실행, 나머지는 무시(스낵바 또는 무반응, 크래시 없음).

tel: 전화 mailto: 메일 sms: 문자(미허용) intent: (차단) javascript: (차단)
스크롤 영역 3

기대: 탭 전환·챌린지 목록으로 이동하며 웹뷰는 닫힌다(이번 런 확정 동작).

챌린지 목록 빵지도 탭 마켓 상품(없는 ID) 미지원 라우트(스낵바)
